# Zdjęcia / Images

Wrzuć tutaj własne zdjęcia i podmień w komponentach `MediaSlot`.

Sugerowane nazwy plików (na później, gdy dojdą kolejne sekcje):

| Plik | Gdzie | Charakter kadru |
| --- | --- | --- |
| `hero.jpg` | Sekcja 01 — Hero | ciemne, kinowe auto (tył / bok), 3:4 pionowo |
| `about.jpg` | Sekcja 02 — O nas | detal pracy / studio |
| `before.jpg` | Sekcja 04 — Efekty (suwak Przed/Po) | matowy / brudny lakier — TEN SAM kadr co after |
| `after.jpg` | Sekcja 04 — Efekty (suwak Przed/Po) | ten sam kadr po detailingu, głęboki połysk |
| `gallery-1.jpg` | Sekcja 06 — Galeria | lakier / refleks |
| `gallery-2.jpg` | Sekcja 06 — Galeria | felga / koło |
| `gallery-3.jpg` | Sekcja 06 — Galeria | wnętrze / skóra |
| `contact.jpg` | Sekcja 07 — Kontakt | auto w ciemnym świetle |

Użycie: `<MediaSlot src="/images/hero.jpg" alt="..." />`.
Bez `src` komponent pokazuje stylizowany placeholder — nic się nie psuje.
